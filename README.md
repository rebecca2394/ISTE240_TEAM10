# StellaVerse - An Educational Learning Platform for Kids

## Project Overview:
We designed a web based educational learning platform for primary and middle school students to help them learn and practice math and science concepts through an interactive and gamified experience. Our platform transforms some of the familiar games that we played in our childhood such as tic-tac-toe, memory cards, hangman, word finder and more, into an interesting knowledge assessment tool where they score and progress in the game when they get their answers correct. The platform features user authentication,progress tracking and administrative interface for managing questions banks.
